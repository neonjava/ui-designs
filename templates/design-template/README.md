## What is in this folder
| File | What it is |
|---|---|
| `brief.md` | The deep brief |
| `prompt.md` | Ready-to-paste prompts |
| `tokens.css` | Copy-paste design tokens |
| `screenshots/` | Numbered screens (desktop and phone) |
| `reference/` | Real code the design was built from (optional) |
| `design.json` | Metadata for the index |

## Use it in a new project
1. Copy `tokens.css` and import it first.
2. Paste `prompt.md` into your AI tool and attach `brief.md`.
3. Check the result against the checklist in `brief.md`.
